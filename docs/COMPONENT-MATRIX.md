# Component inventory

Every component kind is connected to a solver or to the automation graph; equations are in [PHYSICS.md](PHYSICS.md). **E** = MNA electrical; **T** = lumped thermal; **H** = hydraulic/enthalpy; **M** = mechanical midpoint; **C** = simulation-time control; **S** = Planck spatial rigid bodies. Validation references: **legacy** = physics/automation/integrity tests and quantitative report; **hydraulic** = hydraulic tests and coupled reference runs; **browser** = construction, probes, saves, faults and playable challenges. These are coverage categories, not a claim that every combination has been exhaustively tested.

Spatial representations are available for motor, pump, tank, heater, cooler, source, resistor, lamp, pipe and valves. These are optional **static housings of the existing component identity**, not extra catalog entries or new thermal masses. Material thermal properties remain metadata. Fixed, revolute, prismatic, distance, spring and gear/rack constraints are world records with tested solver integration; they are not decorative catalog items. Motor rotor inertia joins the spatial rotor exactly once. Mechanical limitations are in [PHYSICS.md § Rigid bodies and mechanisms](PHYSICS.md#rigid-bodies-and-mechanisms).

## Remaining unsupported extensions

| Requested foundation / extension | Actual status | Rationale / recommended priority |
| --- | --- | --- |
| Dedicated current-source component | No separate catalog entry | The DC supply already supports constant-current regulation with voltage compliance. |
| Distributed radiator / finite air circuit | The panel radiator has finite water and steel storage; the fan-cooled radiator still uses zero inventory. Both exchange with an ideal air boundary | Rooms (finite air and surface capacity), explicit airflow and calibrated fan curves remain deferred. Medium |
| Hydraulic pressure boundary / infinite reservoir | No catalog entry | Finite tanks provide physical boundaries; an expansion vessel sets its sealed circuit's pressure; circuits without one use one pressure datum (externally maintained fill pressure with compliant expansion, no mass source). No standalone infinite reservoir. Low |
| In-line flow meter | Branch probe/sensor implemented | Ideal measurement has no resistance; explicit calibrated meter loss deferred. Low |
| Generic safety interlock | Existing Boolean gates, sensors and motor enable; independent thermal contact | Actual source/high-level logic works. Separate hydraulic latched hardware cutoff and common-cause fault studies remain medium priority |
| Turbine, dedicated generator, semiconductors, steam, structural failure | Unsupported | AC phasors and induction machines are implemented above; these extensions require separate models. |
